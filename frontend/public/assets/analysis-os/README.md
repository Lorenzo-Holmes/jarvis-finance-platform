# JARVIS Analysis OS 3D assets

`jarvis-archive-v1.glb` is an original JARVIS archive model generated from
`tools/blender/build_jarvis_archive_v1.py` with Blender. It is not copied from
RhineLabUI or any third-party game/project asset.

The runtime uses this GLB only for the currently focused/extracted archive.
Far and mid archives keep the lightweight procedural LOD path so the archive
sea remains performant.
