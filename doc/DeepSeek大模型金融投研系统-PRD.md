## 1. 产品概述

### 1.1 产品背景

在金融投研领域，传统工作模式高度依赖分析师人工阅读财报、研报与海量资讯，存在信息处理效率低下、数据分散割裂、投资决策缺乏量化依据等核心瓶颈。大模型技术的快速演进为金融投研的智能化升级提供了全新可能。本项目深度融合 DeepSeek 大模型与金融投研场景，构建覆盖**财报分析、产业链挖掘、智能报价、模拟验证**的全流程投研体系。

### 1.2 产品定位

> **一句话定位**：面向个人投资者与投研人员的，以 **"Python 算数值 + DeepSeek 写文本/推理"** 双轨协作的智能金融投研平台。

平台核心价值主张：**"让投研更智能、更高效、更可信"**，搭建一座连接金融数据与投资决策的智能化桥梁。

### 1.3 产品目标

| 编号 | 目标 | 衡量指标 |
| --- | --- | --- |
| G1 | 建立稳定可靠的黄金行情数据链路 | 行情与 K 线数据与数据源一致，多周期切换正常 |
| G2 | 提供可用的模拟投资验证闭环 | 模拟盘下单/持仓/强平场景全流程走通 |
| G3 | AI 能力覆盖投研核心场景 | AI 对话、财报解析、智能报价、研报情感等能力可演示 |
| G4 | 保证系统稳定与数据安全 | 健康检查与告警链路可用，API Key 安全合规 |
| G5 | 建立可控的身份与运营管理体系 | 支持 GitHub/邮箱登录注册、验证码防滥用、AI 配额与功能权限按用户管理 |

## 2. 目标用户与使用场景

### 2.1 核心用户画像

| 维度 | P1 专业投研分析师 | P2 进阶个人投资者（主力） | P3 私募/独立研究者 | P4 风控/合规决策者（备） |
| --- | --- | --- | --- | --- |
| 一句话定位 | 以财报+产业链为核心产出深度结论 | 先回测、再模拟、后实盘 | 以风险+多空研报为核心做组合研究 | 以风险计算把关仓位与回撤 |
| 基础属性 | 28-45 岁，券商/基金研究所研究员 | 30-50 岁，互联网/金融从业者 | 35-55 岁，私募/独立研究者 | 30-50 岁，机构风控/合规岗 |
| 行为特征 | 高频使用财报解析、产业链挖掘 | 每日盘中刷多周期 K 线，周末跑回测 | 批量聚合研报、盯风险指标 | 核查强平规则、出风控报告 |
| 核心诉求 | 30 分钟完成"财报×产业链×情绪"三维交叉验证 | 回测通过→模拟盘加杠杆→小额实盘 | 一周产出标的池+多空信号+风险评分 | 审查风险逻辑、输出可追溯风控报告 |

### 2.2 核心使用场景

1. **行情跟踪**：登录后查看黄金 ETF、伦敦金、积存金的实时价格与多周期 K 线，把握当日盘面。
2. **策略验证**：在模拟盘/回测模块用双均线等策略对历史行情复盘，用虚拟资金加杠杆试单。
3. **AI 投研**：向"库里帕酱"提问研报解读、产业链逻辑、智能报价解读。
4. **财报解析**：上传 PDF/图片财报，自动提取核心财务数据并结构化输出。

### 2.3 用户核心痛点映射

| 痛点 | 解决方案 |
| --- | --- |
| 研报信息过载，人工阅读效率低 | AI 对话式研报解读、智能摘要 |
| 信息噪音大，关键信号被淹没 | 研报情感分析、争议点梳理 |
| 数据分散割裂，整合成本高 | 统一行情数据链路、财报 OCR 结构化 |
| 决策缺乏量化依据 | 回测、智能报价、趋势预测 |
| 风险识别滞后 | 风险指标（VaR/ES）、超阈值预警 |

## 4. 功能需求

### 4.1 功能清单总览（优先级分布）

| 优先级 | 数量 | 功能 |
| --- | --- | --- |
| P0 | 5 | 用户中心、行情中心、AI 智能对话、模拟盘交易、策略回测 |
| P1 | 6 | 财报智能解析、智能询报价、研报情感分析、产业链挖掘、风险预警、账户与权限管理 |
| P2 | 3 | 个性化策略生成、市场趋势预测、运维监控 |

### 4.2 功能需求详表

功能需求编号 FR-01 ~ FR-14，与需求调研报告功能清单 F001 ~ F014 一一对应。

#### FR-01 用户身份与登录管理（GitHub/邮箱）｜P0

- **功能描述**：支持 GitHub OAuth 登录/注册与邮箱登录/注册。邮箱注册、找回密码和必要的高风险操作通过 Resend 发送一次性验证码，完成邮箱真实性校验并降低注册机滥用；登录后签发 JWT 会话，支持会话保持、登出和个人资料维护。
- **邮箱登录/注册**：支持邮箱+密码注册和登录；新邮箱必须先完成验证码校验；验证码不明文落库，具备有效期、单次使用、错误次数上限和过期机制。
- **GitHub 登录/注册**：采用 OAuth 2.0 Authorization Code 流程；服务端保存 GitHub 用户唯一标识，首次登录自动创建账户，已注册邮箱可在完成身份确认后绑定 GitHub 登录方式。
- **防滥用策略**：验证码发送设置邮箱/IP/设备维度的频率限制与冷却时间；登录、注册、验证码校验失败达到阈值后临时限制；错误提示不得泄露邮箱是否已注册。
- **交互**：登录页提供 GitHub 登录、邮箱登录、邮箱注册、验证码输入、重新发送和找回密码入口；登录成功后进入工作台，右上角显示用户信息与退出按钮。
- **验收要点**：GitHub 首次登录与绑定、邮箱注册验证、邮箱登录、验证码过期/重复使用/超限、登出、非法令牌拦截和限流用例通过。

#### FR-02 行情中心（实时行情与 K 线）｜P0

- **功能描述**：多标的（黄金ETF 518850、伦敦金 XAUUSD、积存金）实时报价与多周期 K 线（日/1/5/15/30/60 分）展示，ECharts 可视化；历史数据落库可追溯；数据源以腾讯财经为主，预留多数据源切换。
- **交互**：顶部实时价格卡片（含涨跌）、下方 K 线面板（周期/数量切换、缩放、十字光标）。
- **验收要点**：报价与 K 线数据与源一致；周期切换正常；断网有缓存兜底。

#### FR-03 AI 智能对话（投研助手）｜P0

- **功能描述**：基于 DeepSeek 的对话式投研助手（"库里帕酱"），支持自然语言问答、研报内容解读、投资逻辑梳理；**架构铁律**：量化指标与数值计算 100% 由 Python 完成，模型仅负责因果推理与文本生成；持仓建议提示风险、不承诺收益。
- **交互**：聊天窗口流式输出；快捷问题引导；AI 能力状态展示。
- **验收要点**：多轮对话可用；数值口径正确；风险提示生效。

#### FR-04 模拟盘交易｜P0

- **功能描述**：虚拟资金模拟账户、持仓管理与交易撮合，支持 1-5x 杠杆与保证金强平；资金与成交记录可查；仅使用虚拟资金，不构成真实投资建议。
- **交互**：下单表单（标的/买卖/数量/杠杆）、持仓列表（可快速平仓）、成交记录、账户资产汇总。
- **验收要点**：下单/持仓/强平场景走通，杠杆与保证金计算正确。

#### FR-05 策略回测｜P0

- **功能描述**：双均线（快/慢均线参数可调）策略回测引擎，输出收益、回撤与逐日净值曲线，结果可复现。
- **交互**：参数输入（快线/慢线/本金）→ 运行回测 → 指标卡 + 净值曲线 + 近期交易明细。
- **验收要点**：回测结果可复现且与净值曲线一致。

#### FR-06 财报智能解析｜P1

- **功能描述**：支持 PDF/图片财报的 OCR 文本抽取与复杂排版处理；自动提取营收、利润、资产负债等核心财务数据及战略调整等非财务信息；输出结构化 JSON，结合知识图谱关联行业数据；多轮交叉验证保障准确性。
- **交互**：上传/粘贴财报 → 解析进度 → 结构化结果展示（财务指标表 + 关键事件）。
- **验收要点**：示例财报解析输出结构化 JSON 且关键字段准确。

#### FR-07 智能询报价与价格走势预测｜P1

- **功能描述**：综合市场供需、行业竞争态势、公司财务状况等因素，基于统计与时序基线模型输出报价参考与未来价格走势趋势区间，由 DeepSeek 生成 LLM 解读；行情为日级更新，非秒级实时。
- **交互**：一键生成"智能报价解读"卡片，展示现价/涨跌/趋势区间/要点。
- **验收要点**：预测输出区间与解读可展示。

#### FR-08 研报情感分析与争议点梳理｜P1

- **功能描述**：对海量研报进行文本聚类与情感分析，提炼核心观点、行业趋势判断、评级与目标价；对观点相左的研报通过论据与逻辑对比梳理争议焦点。
- **交互**：研报列表 → 情感标注（看多/看空/中性）→ 争议点对比卡片。
- **验收要点**：情感摘要与争议点列表可展示。

#### FR-09 产业链深度挖掘｜P1

- **功能描述**：基于知识图谱构建产业链上下游关系模型，运用思维链与因果推理分析技术创新、政策变动等动态因素的传导效应，输出产业链视图。
- **交互**：输入产业链节点（如"黄金"）→ 输出上下游关系、供需、关键厂商、景气度、投资逻辑。
- **验收要点**：产业链视图与传导路径可展示。

#### FR-10 风险预警模型｜P1

- **功能描述**：实时监测原材料中断、政策变动等外部冲击，量化市场风险/信用风险/流动性风险（VaR、ES 等指标）；超阈值触发预警并生成风险来源、影响范围与应对建议报告。
- **交互**：风险仪表盘（指标数值 + 阈值状态）+ 预警卡片。
- **验收要点**：超阈值触发预警并输出风险报告。

#### FR-11 个性化策略生成｜P2

- **功能描述**：基于情景假设与风险偏好问卷，结合用户画像生成展示型配置建议与个性化投资策略；深度学习预测模型为增量迭代内容，本期不纳入硬性验收指标。
- **验收要点**：策略卡片可展示（演示型）。

#### FR-12 市场趋势预测｜P2

- **功能描述**：整合宏观经济（GDP、利率、汇率）、行业（增长率、市场份额）、企业微观与舆情多维度数据，运用时间序列分析与机器学习分类算法预测不同资产类别市场走势。
- **验收要点**：预测结果与依据可展示。

#### FR-13 运维监控｜P2

- **功能描述**：对前端、后端、AI 微服务运行状态及 DeepSeek API 调用情况进行监控；异常通过 OpenClaw 巡检告警通知；保障系统稳定性、金融数据隐私与 API Key 安全合规。
- **验收要点**：健康检查与告警链路可用。

#### FR-14 管理员账户、AI 配额与功能权限｜P1

- **功能描述**：提供管理员后台，管理员可以查询和管理用户账户，分配 AI 使用配额与功能权限，查看使用情况及关键操作审计记录。
- **账户管理**：支持用户搜索、详情查看、启用/禁用账户、重置登录状态、查看注册方式和最近登录信息；管理员操作不得直接暴露用户密码或第三方 OAuth 密钥。
- **AI 配额管理**：支持按用户或用户组配置请求次数、Token 或周期额度（日/月）；记录额度发放、消耗、调整和剩余量；额度不足时阻止 AI 请求并返回明确提示，管理员调整必须填写原因。
- **功能权限管理**：采用 RBAC 和功能权限组合，至少区分普通用户与管理员；高成本或灰度功能可按用户、用户组配置；权限必须在后端接口层强制校验，前端隐藏不能替代后端鉴权。
- **审计与安全**：记录管理员登录、账户状态变更、配额调整、权限变更和批量操作，审计记录包含操作者、目标用户、时间、来源 IP、变更前后摘要和操作原因。
- **验收要点**：管理员与普通用户权限隔离、账户禁用立即生效、配额原子扣减与周期重置、额度不足拦截、功能权限后端校验、管理员操作审计和越权访问拦截用例通过。

## 5. 非功能需求

### 5.1 性能需求

| 项目 | 要求 |
| --- | --- |
| 页面首屏加载 | ≤ 3s（网络正常时） |
| 行情刷新 | P0 实时行情秒级 / 分时刷新（轮询 ≤30s）；K 线日级落库 |
| AI 首 token 响应 | ≤ 5s（模型可用时） |
| 并发 | 支持 ≥ 20 并发访问（教学/个人场景） |

### 5.2 安全与合规

- JWT 认证：登录令牌签发/校验/过期，敏感接口鉴权。
- 第三方登录：GitHub OAuth 的 client secret 仅保存在服务端；OAuth 流程校验 state，支持 PKCE 时必须启用；回调地址采用白名单配置。
- 邮箱验证：Resend API Key 仅保存在服务端；验证码设置有效期、单次使用、错误次数上限、发送冷却和多维度限流，避免账号枚举和批量注册。
- 权限与配额：管理员接口采用后端 RBAC 校验；AI 配额扣减必须具备并发安全性，不能仅依赖前端计数。
- 隐私合规：金融数据仅用于本系统教学与研究场景；DeepSeek API Key 不在前端暴露。
- 合规声明：所有模拟盘功能使用虚拟资金，页面明示"仅供研究参考，不构成投资建议"。
- 审计：关键操作（下单、登出、管理员账户变更、配额调整、权限变更）记录可追溯。

### 5.3 可用性与可靠性

- 多数据源容错：行情主源（腾讯）失败自动切换备用源（新浪）；网络失败时使用本地缓存兜底。
- 服务健康检查：`/api/health` 与 AI 能力状态端点；异常告警（OpenClaw 巡检）。

### 5.4 兼容性

- 现代浏览器（Chrome/Edge 最新两个大版本）。
- 桌面优先，支持 1280px 以上；窄屏自适应降级为单列布局。

## 7. 视觉与交互设计规范（V1.0）

> 详见原型页面与之配套的设计规范。此处为关键决策摘要。

### 7.1 设计风格

**深色金融终端风（Dark Fintech）**。延续系统既有视觉基因，定位"专业、克制、重数据"。整体采用深蓝底色 + 信息卡片化布局，突出行情数字与 K 线图表，弱化装饰，保证数据可读性与专业可信度。

### 7.2 配色规范

| 令牌 | 色值 | 用途 |
| --- | --- | --- |
| `--bg` | `#0b1020` | 页面背景 |
| `--panel` | `#121a2d` | 卡片/面板背景 |
| `--line` | `#243453` | 边框/分割线 |
| `--text` | `#e9effb` | 主文本 |
| `--muted` | `#8ba0c8` | 次要文本 |
| `--accent` | `#4da8ff` | 主强调色（蓝） |
| `--accent-2` | `#a842ff` | 渐变副色（紫） |
| `--up` | `#ef5350` | 上涨/阳线（红） |
| `--down` | `#27c46b` | 下跌/阴线（绿） |
| `--gold` | `#f5c542` | 积存金/黄金专属高亮 |

**设计决定**：遵循中国市场惯例，**红涨绿跌**（K 线阳红阴绿，涨跌幅度红涨绿跌），与 K 线配色保持一致。

### 7.3 布局规范

- 内容最大宽度 1200px，居中，页脚合规声明。
- 顶部导航：品牌 Logo（渐变）+ 页面 Tab；右侧用户信息/连接状态。
- 实时价格卡：两列均分（移动端单列），顶部 3px 渐变装饰条，价格大字号 tabular-nums。
- K 线图：面板内嵌，下方周期/数量控件。
- 指标卡区：`repeat(auto-fit, minmax(140px,1fr))` 自适应网格。

### 7.4 交互设计规范

| 交互 | 说明 |
| --- | --- |
| 导航 | Tab 点击切换页面，激活态渐变底 |
| 按钮 | 主按钮蓝紫渐变；次要按钮深色描边；禁用态降透明度 |
| 数据刷新 | 实时行情 30s 轮询（原型以静态模拟数据演示） |
| K 线交互 | hover 十字光标、滚轮缩放、底部滑块 |
| 下单交互 | 表单即时校验；成功后顶部提示条 + 持仓/成交联动刷新 |
| 对话交互 | 流式输出；快捷问题一键填充输入框 |
| 空状态/错误 | 错误提示条（红底）、加载中禁用按钮 |

## 10. 风险与开放问题

| 风险/问题 | 级别 | 应对 |
| --- | --- | --- |
| 免费行情源不稳定/被限流 | 中 | 多源切换 + 本地缓存兜底（已实现） |
| DeepSeek API 限额/延迟 | 中 | 流式输出 + 状态监控 + 降级提示 |
| GitHub/Resend 服务不可用或回调异常 | 中 | 超时与重试、备用邮箱提示、OAuth 回调白名单、登录方式降级 |
| 验证码接口被刷或批量注册 | 高 | 邮箱/IP/设备限流、验证码冷却、单次消费、风控审计 |
| AI 配额或功能权限被越权修改 | 高 | 后端 RBAC、事务性扣减、管理员操作审计与告警 |
| 大模型数值幻觉 | 高 | 架构铁律：数值计算全部 Python 完成 |
| 数据合规（金融数据） | 中 | 仅限教学研究用途声明 + 不暴露 Key |
| 线上 DNS/网络故障 | 低 | 部署侧已配置公共 DNS 冗余（items from prior session） |
