## 第一章 产品经理的角色职责

### 1.1 产品经理的核心定位

产品经理是连通用户、技术与商业的枢纽角色。在AI时代，虽然AI可以辅助数据分析、生成用户画像初稿、自动整理竞品信息，但以下能力是**AI不可替代**的：

| AI可替代    | AI不可替代                 |
| -------- | ---------------------- |
| 数据采集与清洗  | **价值判断**：什么值得做、为什么做    |
| 生成用户画像初稿 | **同理心共情**：深入理解用户情感与场景  |
| 统计竞品功能列表 | **战略决策**：资源有限时选择放弃什么   |
| 整理需求清单   | **逻辑验证**：识别伪需求，挑战业务方假设 |

### 1.2 需求调研中的AI不可替代能力

**（1）场景式提问能力**

AI可以列出问题模板，但只有PM能在真实场景中追问出深层需求。例如用户说"想要更准的研报"，PM需要追问"是内容不够新？还是观点不够有依据？还是读起来太累？"

**（2）跨需求冲突权衡**

不同用户群体需求互相矛盾时，PM需要基于商业战略做出取舍。例如免费用户想要全部数据免费 vs 付费用户想要专属深度报告。

**（3）隐性需求洞察**

用户说的 ≠ 用户真正想要的。PM需要从"行为"而非"言语"中发现真实诉求。例如用户频繁切换周期K线，说明真正想要的是"趋势确认工具"而非"更多图表"。

**（4）干系人管理与推动落地**

协调开发、设计、运营、管理层多方利益，推动需求从 idea → 落地 → 迭代的全流程。

### 1.3 需求调研的完整流程

```
用户画像 → 需求收集 → 数据分析 → 竞品分析 → 功能矩阵 → 需求报告
```

### 1.4 本项目调研概述

DeepSeek 大模型金融投研系统（工程代号：JARVIS 积存金智能模拟交易助手）深度融合大模型技术与金融投研场景，构建覆盖**财报分析、产业链挖掘、智能报价**的全流程投研体系。本报告围绕该系统的需求调研过程展开，涵盖用户画像、竞品分析、功能矩阵分解与需求落地建议，为后续产品设计提供决策依据。

## 第二章 用户画像分析

### 2.1 什么是用户画像（Persona）

用户画像是**基于真实数据构建的典型用户角色模型**，帮助团队将抽象的用户群体转化为具象的、可理解的典型角色，为后续功能设计提供决策依据。

对金融投研工作台而言，用户画像有三重价值：

1. **指导 AI 人设与提示词**：投研 AI（"库里帕酱"）的对话风格、专业深度、输出结构，取决于为谁服务
2. **决定功能优先级**：专业分析师看重产业链图谱，个人投资者更看重回测与模拟盘——画像直接决定 P0/P1/P2
3. **支撑风控与合规**：不同用户的杠杆承受度、风险偏好不同，画像数据是"风险计算"模块的输入之一

### 2.2 用户画像的核心要素

预设的产品：金融投研工作台

| 要素        | 说明               | 示例                               |
| --------- | ---------------- | -------------------------------- |
| **基础属性**  | 年龄、职业、教育背景、投资经验  | "32岁互联网从业者，本科学历，5年投资经验，个人投资者"    |
| **行为特征**  | 使用频率、设备偏好、内容消费习惯 | "每天盘中刷行情K线，周末跑回测，偏好15分钟内的AI研报摘要" |
| **需求痛点**  | 现有平台未满足的诉求       | "券商研报太长太专业，找不到能直接指导决策的多空结论"      |
| **场景与目标** | 典型使用场景与核心目标      | "投资黄金ETF前，先用模拟盘验证策略、用AI核对多空逻辑"   |

### 2.4 用户痛点分析

通过对目标用户的深度调研，识别出以下五大核心用户痛点：

**痛点一：研报信息过载，人工阅读效率低下。** 传统投研高度依赖分析师逐篇阅读财报与研报，一名分析师每天需处理数十份公告、研报与新闻，人工筛选、归纳、提炼结论耗时巨大，人均信息处理能力已成为投研效率的硬瓶颈。用户迫切需要一个能够自动完成信息提取、归并与摘要的智能工具。

**痛点二：信息噪音大，关键信号被淹没。** 金融信息来源庞杂，新闻、公告、研报、社交平台观点真假混杂、相互对立，缺乏自动化的信息清洗与情感判断能力。投资者难以快速识别真正影响资产价格的核心变量，往往在冗余信息中耗费大量精力，甚至被误导性信息带偏决策方向。

**痛点三：数据分散割裂，整合成本高。** 财报、行情、行业数据分散在不同平台与格式中，PDF、图片、非结构化文本与结构化数据并存，缺乏统一的数据层整合能力。用户需要花费大量时间进行数据清洗、对齐与标准化，数据壁垒直接拉高了投研的前期成本。

**痛点四：决策缺乏量化依据，主观性强。** 传统投研主要依赖经验判断与定性分析，缺少量化指标、趋势预测区间与情景假设分析作为决策支撑，投资建议的科学性与可追溯性不足。用户在面对"该买还是该卖"的决策节点时缺少客观参照，容易受情绪与短期波动干扰。

**痛点五：风险识别滞后，缺乏预警机制。** 产业链上下游的风险传导、企业财务指标的恶化往往在事后才被发现，缺乏基于因果推理与知识图谱的实时风险预警能力。当风险指标超过阈值时，用户无法第一时间获知风险来源、影响范围与应对建议，面对突发风险时应对被动。

## 第三章 竞品分析

### 3.1 竞品分析的目的

通过系统性研究市场上同类产品的功能与策略，快速定位自身产品的**差异化机会**，并为需求优先级排序提供客观依据。

### 3.2 竞品选择策略

| 竞品类型     | 定义            | 示例（金融投研工作台）                            |
| -------- | ------------- | -------------------------------------- |
| **直接竞品** | 功能高度重合的产品     | 同花顺 iFinD/问财、萝卜投研（通联数据）、东方财富 Choice/妙想 |
| **间接竞品** | 满足相同需求的不同形式产品 | DeepSeek/Kimi 通用大模型直接问答、慧博智能终端（研报聚合）   |

### 3.3 竞品概述一：同花顺 iFinD

**产品名称**：同花顺 iFinD 金融数据终端

**产品定位**：同花顺 iFinD 由杭州同花顺数据开发有限公司推出，是面向机构投资者的金融数据终端，覆盖股票、债券、外汇、期货、基金、理财、指数等业务品种，提供企业库、宏观数据、产业链等专业数据服务。近年来 iFinD 全面升级为"基于 AI 金融大数据的智能投研平台"，主打"数据创造价值，AI 助力投研"，通过机器学习、NLP、知识图谱等 AI 技术对全网数据进行自动化处理与分析。

**核心功能**：iFinD 的核心功能围绕"数据 + AI"两大支柱展开。数据终端模块覆盖 300+ 数据维度、330 万+ 指标。智能资讯模块实现全网信息自动聚合，日更新新闻 3000+ 条。产业洞察模块提供 11 级产业分类体系、100+ 精选产业链。AI 预测模块运用深度学习、集成学习等模型，提供宏观/中观/微观三维度 AI 预测与策略回测能力。知识图谱与 NLP 模块整合深度学习、本体推理与因果推理技术，实现研报观点自动提取与情感分析。

**优势总结**：数据覆盖全面，AI 技术积累雄厚，品牌与渠道优势明显，行业解决方案成熟。

**劣势总结**：重量级终端定位导致价格高、门槛高；功能模块复杂，学习成本高；缺乏"投研—模拟验证"一体化闭环。

### 3.4 竞品概述二：萝卜投研（通联数据）

**产品名称**：萝卜投研（Datayes!Pro）

**产品定位**：萝卜投研由通联数据股份公司推出，是国内首个基于"大数据和机器学习"的智能投研平台。核心主张是"无依据，不投资"，利用人工智能、大数据、移动应用技术，高效处理投资资讯、公告、研报、财报、数据等信息，满足用户在股票证券研究、价值投资分析、FOF 等资产管理场景下的需求。

**核心功能**：智能搜索模块支持对公告、研报、新闻的聚合检索与智能关联。财报与财务分析模块提供结构化财报数据与财务指标分析工具。金融知识图谱模块构建个股—产业链—上下游企业的关系网络。个股盈利预测模块基于 AI 模型输出上市公司盈利预测。智能监控模块支持自选股异动监控。组合穿透管理模块面向 FOF 与资产管理场景。

**优势总结**："大数据 + AI"定位清晰，在智能投研赛道布局早、产品认知度高；产业链数据积累深厚；产品轻量易用，B 端 C 端兼顾。

**劣势总结**：数据广度与机构基础设施不如同花顺 iFinD；缺少大模型生成式能力；缺乏模拟盘验证闭环；贵金属等另类资产覆盖有限。

### 3.6 SWOT 综合评估（以同花顺 iFinD 为例）

#### 优势（Strengths）

1. 数据覆盖全面，八大业务品种、300+ 数据维度、330 万+ 指标构成深厚的数据基础设施，机构客户依赖度高。
2. AI 技术积累雄厚，NLP、知识图谱、深度学习预测模型在金融场景落地成熟，技术护城河明显。
3. 品牌与渠道优势突出，同花顺在金融信息服务领域市占率高，机构客户资源丰富。
4. 行业解决方案成熟，银行、券商、基金等场景均有完整落地方案。

#### 劣势（Weaknesses）

1. 重量级终端定位，价格高昂，个人投资者与高校教学用户难以负担。
2. 功能模块众多、信息密度高，学习成本大，用户体验偏工程化。
3. 缺乏"投研—模拟验证"一体化闭环，AI 能力以工具形式存在，服务体验不完整。

#### 机会（Opportunities）

1. 大模型浪潮推动投研智能化升级，生成式 AI 投研产品存在广阔增量空间。
2. 个人投资者与高校金融教育市场对低成本、易上手的智能投研工具需求持续上升。
3. 金融数据合规与自主可控要求带来国产替代与差异化竞争机会。

#### 威胁（Threats）

1. 萝卜投研、东方财富 Choice 等同业持续加码 AI 投研，竞争加剧。
2. DeepSeek、通义等大模型厂商可能向下延伸金融应用，形成生态级竞争。
3. 数据源成本上升与监管对金融 AI 应用合规性的约束趋严。

## 第四章 产品的功能矩阵分解

### 4.1 功能矩阵的定义

功能矩阵是将用户需求、竞品对比结果转化为**具体功能清单**的工具。它帮助确定 **"做什么、不做什么、优先做什么"**。

### 4.2 从需求到功能的转化路径

```
用户痛点 → 用户需求 → 功能需求 → 功能模块 → 功能清单
```

### 4.3 需求漏斗模型（优先级排序）

使用需求漏斗模型分析用户价值与实现成本，设置需求优先级：

| 优先级    | 定义          | 示例                       |
| ------ | ----------- | ------------------------ |
| **P0** | 核心必备，不做无法上线 | 行情可视化、AI问答、模拟盘交易、用户认证    |
| **P1** | 重要功能，提升体验   | 财报智能解析、回测引擎、产业链图谱、研报情感分析 |
| **P2** | 锦上添花，持续迭代   | 个性化策略生成、市场趋势预测、运维监控      |

## 第五章 产出需求调研报告

### 5.1 需求调研报告的结构

本报告按照以下标准结构组织：

```
1. 调研背景与目标
2. 调研方法说明
3. 用户画像分析（核心用户群体特征）
4. 竞品分析（直接竞品与间接竞品对比）
5. 功能矩阵与需求清单（含优先级排序）
6. 需求落地建议（迭代路线图）
7. 附录（数据来源说明）
```

### 5.2 报告撰写要点

| 要点        | 说明                    |
| --------- | --------------------- |
| **结论先行**  | 每部分开头给出核心结论，再展开论据     |
| **数据支撑**  | 所有判断基于公开竞品信息与代码仓库功能事实 |
| **可视化呈现** | 使用表格展示用户画像、功能矩阵、优先级分布 |
| **可落地**   | 报告结论直接指导产品设计和开发排期     |
| **AI辅助**  | 使用AI生成初稿，但需人工审核逻辑与判断  |

### 5.3 核心结论

**（1）市场定位**：头部竞品在数据广度与研报深度上全面领先，但在"策略回测 + 模拟盘 + 黄金垂直"组合上存在空白——这构成了本平台 v1 的核心差异化立足点。

**（2）目标用户**：以 P2 进阶个人投资者为主力用户（与现有模拟盘 + 黄金行情用户画像高度吻合），以 P1 专业投研分析师为产品升级方向。

**（3）功能优先级**：P0 核心功能（行情、AI对话、模拟交易、回测、用户认证）构成 MVP 基线；P1 功能（财报解析、产业链、研报情感、风险预警、账户与权限管理）是差异化竞争力和平台可控运营的关键；P2 功能（策略生成、趋势预测、运维监控）为持续迭代方向。

**（4）迭代路线图建议**：

| 阶段  | 时间             | 重点                    |
| --- | -------------- | --------------------- |
| MVP | 08-31 \~ 09-06 | 行情数据链路、核心 API、P0 功能   |
| 增强  | 09-07 \~ 09-13 | DeepSeek 投研能力、P1 功能联调 |
| 完善  | 09-14 \~ 09-20 | 双端界面、研报情感、产业链、风险预警    |
| 交付  | 09-21 \~ 09-27 | 全量测试、文档齐备、结题交付        |

### 5.4 从调研到落地的闭环

```
需求调研 → 调研报告 → 需求评审 → PRD撰写 → 开发迭代 → 数据验证 → 下一轮调研
```

## 课程总结

| 章节       | 核心能力                 | AI赋能点          | AI不可替代点          |
| -------- | -------------------- | -------------- | ---------------- |
| 产品经理角色职责 | 价值判断与决策              | 数据整理初稿、调研流程自动化 | 取舍抉择、共情洞察        |
| 用户画像分析   | 构建精准 Persona（P1-P4）  | 提示词生成初稿        | 场景理解、问题深挖、真实访谈验证 |
| 竞品分析     | 差异化定位（回测+模拟盘+黄金垂直空档） | 功能列表收集、竞品界面截图  | 战略方向判断           |
| 功能矩阵分解   | 需求优先级排序（P0/P1/P2）    | 需求聚类整理         | 商业价值权衡           |
| 产出调研报告   | 系统性输出                | 报告草稿生成         | 逻辑验证与最终决策        |

> **核心理念**：AI是强大的辅助工具，但产品经理的核心竞争力在于**对用户的深度理解、对商业的判断力、对需求的逻辑验证**——这些是AI无法替代的。
